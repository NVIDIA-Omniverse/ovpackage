# Omniverse ovpackage

Workflow for Reproducible Asset Packaging and Publishing

ovpackage provides a command line tool that is able to execute a set of useful packaging and distribution functions. E.g. to define sets of versioned files,
label them, and distribute and consume versions in a safe manner.

ovpackage is distributed as a Python wheel through the NVIDIA published package at this repository.
See the Tutorials for step-by-step installation instructions.
