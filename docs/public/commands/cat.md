# Cat

## Description

Print the content of a file (text file) to the console.

For viewing the content of a single text file, you can issue the cat command and ovpackage will download the content
and print it to stdout.

For CLI options, run `ovpackage cat --help`.

See the `ovpackage.commands.cat.cat` function docstring for the full Python API reference (signature, parameters, and error handling).
